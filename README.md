# 自动下一步

一个原生 Android 自动化工具：通过无障碍服务识别第三方应用当前页面中的“下一步”“继续”“Next”或“Continue”控件，并在匹配后自动点击。

## 构建

本机需要 Android SDK、Java 17 和 Gradle 8.x。项目使用 Android Gradle Plugin 8.7.3、`compileSdk 35`。

```bash
gradle :app:assembleDebug
```

生成的 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。

## 使用

1. 安装 APK 并打开“自动下一步”。
2. 可填写目标游戏包名；留空时会匹配所有第三方应用。
3. 点击“保存目标应用”，再点击“打开无障碍设置”。
4. 开启“自动下一步无障碍服务”。
5. 返回目标游戏。无障碍服务启动前台自动点击服务后，会显示常驻通知；IO 协程每 2 秒发送一次交替点击指令，仅当目标应用位于前台时执行手势，同时继续识别并点击可访问的匹配按钮。

无障碍服务具有读取屏幕内容和执行点击操作的能力，请只对自己有权操作的应用启用，并在使用完成后关闭服务。
